# CSV Import Readiness Checker

Бесплатная локальная проверка небольшого обезличенного CSV-фрагмента перед импортом в amoCRM, Битрикс24 или другую CRM. Данные обрабатываются только в браузере: сервер, аналитика, cookies и внешние API не используются.

## Что проверяет

- разделитель: запятая, точка с запятой, табуляция или `|`;
- одинаковое число колонок во всех строках;
- пустые и повторяющиеся заголовки;
- пропущенные ячейки;
- точные дубли строк без автоматического удаления;
- базовый формат email и телефона;
- ячейки, похожие на формулы и начинающиеся с `=` или `@`;
- не более 50 строк и 200 000 символов за одну проверку.

Это предварительная структурная диагностика. Она не определяет бизнес-правила дублей, не объединяет клиентов, не исправляет файл и не заменяет тестовый импорт.

## Безопасность данных

Не вставляйте реальные имена, клиентские записи, пароли, токены или другие персональные данные. Используйте только синтетический или заранее обезличенный фрагмент. Код не содержит сетевых запросов, форм отправки или телеметрии.

## Запуск

Нужен любой локальный HTTP-сервер, потому что интерфейс загружает ES-модуль:

```powershell
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Тесты

Зависимости не требуются. Нужен Node.js 18 или новее:

```powershell
npm test
```

Тесты покрывают quoted CSV, escaped quotes, определение разделителя, ограничения размера, дубли, разную ширину строк, заголовки, email/телефоны и formula-like значения.

## English

This is a local-only structural checker for a small anonymized CSV sample before CRM import. It detects delimiters, inconsistent row widths, missing cells, duplicate headers and exact rows, basic email/phone issues, and formula-like values. It does not upload or modify data and does not infer business deduplication rules.
